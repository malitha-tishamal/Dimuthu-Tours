1. Project Overview

The Dimu Tour & Traveling website is a high-performance, responsive web application built for a premier tourism and taxi service provider in Sri Lanka. It replaces traditional static information with a dynamic, data-driven experience. The application features a stunning customer-facing frontend to explore tours, safaris, and vehicle options, paired with a robust administrative dashboard for comprehensive business management. By integrating real-time lead generation via WhatsApp and an asynchronous booking system, the platform ensures maximum conversion and operational efficiency.

4. Frontend Module Detailed View

4.1 index.php (The Hub)

The primary entry point. It dynamically orchestrates the loading of all business content from the database. It features a hero slider, tour cards, safari highlights, vehicle galleries, and the travel memory blog.

Logic BlockDescription
Hero Slider QueryFetches all active hero slides from `hero_slides` table to populate the top banner.
Tour Card FetchRetrieves active tour packages, including their day-by-day itineraries for modal display.
Vehicle Fleet QueryPulls vehicle specs and links to the `vehicle_images` table for the gallery.
AJAX IntegrationInitializes Fetch API listeners for the booking and review forms to prevent page reloads.

4.2 booking.php

A headless PHP script designed to process incoming customer leads asynchronously. It ensures data integrity and triggers the communication pipeline.

Logic BlockDescription
Input SanitizationTrims and filters all incoming POST data to prevent malicious injections.
Lead CaptureInserts the inquiry details into the `bookings` table for long-term tracking.
WhatsApp Link GeneratorDynamically constructs a pre-filled WhatsApp URL and returns it in the JSON response.

5. Admin Module Detailed View (lib/admin/)

5.1 dashboard.php

Provides a real-time snapshot of the business operations. It calculates key metrics from across the database.

StatisticSource Calculation
Total Tours`SELECT COUNT(*) FROM tours`
Total Bookings`SELECT COUNT(*) FROM bookings`
Total Reviews`SELECT COUNT(*) FROM reviews`
Active Vehicles`SELECT COUNT(*) FROM vehicles WHERE status='active'`

5.2 tours.php

The core content management script for tour packages. It handles complex data entry and media management.

Function / LogicDescription
_addTour()Handles the multipart form data, validates the image upload, and generates a new record.
_editTour()Allows modification of titles, descriptions, and durations with optional image replacement.
_toggleStatus()Instantly publishes or unpublishes a tour from the frontend using a single SQL update.
_deleteTour()Removes the tour record and any associated itinerary days from the system.

5.3 tour_itinerary.php

A specialized sub-manager for the day-by-day breakdown of tours, providing high-resolution details to potential customers.

Function / LogicDescription
_addDay()Links a specific itinerary day to a parent tour ID.
_reorderDays()Allows admins to adjust the sequence of events within a tour package.
